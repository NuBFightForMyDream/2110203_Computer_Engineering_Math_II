Quantum Fourier |n⟩ ↦ (1/√N) Σk ej2πnk/N|k⟩

ที่เรียกกันว่า “quantum Fourier” คือ DFT ตัวเดียวกับใน Lecture 04 แค่ข้อมูลไม่ได้อยู่ใน array แต่เป็น amplitude ของ qubit หน้านี้ไล่จากเรื่องที่เรียนแล้ว (DFT, FFT, สมบัติเลื่อนเวลา, leakage) ไปจนถึงเหตุผลที่มันทำให้ Shor's algorithm แยกตัวประกอบได้เร็ว — เนื้อหาเสริม ไม่อยู่ในสไลด์ของวิชา

01 QFT คือ DFT ที่ใส่ไว้ใน amplitude — สูตรเดียวกัน ต่างแค่ 2 จุด

สถานะของ q qubit คือเวกเตอร์ของจำนวนเชิงซ้อน N = 2q ตัว x0, …, xN−1 ที่ Σ|xn|2 = 1 — มองเป็นสัญญาณ discrete ยาว N จุดได้เลย QFT ทำกับเวกเตอร์นี้แบบเดียวกับ DFT ทุกอย่าง ต่างกันแค่ หารด้วย √N (ให้ความน่าจะเป็นรวมยังเป็น 1 — คือ Parseval) และ เครื่องหมายในเลขชี้กำลังเป็นบวก

วางเทียบกัน

DFT: X[k] = ΣN−1n=0 x[n] e−j2πkn/N
QFT: yk = 1√NΣN−1n=0 xn e+j2πkn/N
|n⟩สถานะที่อ่าน qubit ทั้งหมดเป็นเลขฐานสองได้ n
xnamplitude (เชิงซ้อน) ของ |n⟩
|xn|²ความน่าจะเป็นที่วัดแล้วได้ n
1/√Nทำให้ Σ|yk|² = Σ|xn|² (Parseval)

ใน numpy: y = np.fft.ifft(x) * np.sqrt(N) · หนังสือฟิสิกส์เขียน i แทน j — หน้านี้ใช้ j ตามสไลด์วิชา

02 QFT ของ |n⟩ แยกเป็นวงล้อเฟสทีละ qubit — เพราะอย่างนี้วงจรถึงสั้น

ถ้าเข้าเป็น basis |n⟩ (impulse δ[·−n]) ผลคือ exponential ej2πnk/N/√N — เหมือน δ[n−n₀] ↔ e−jωn₀ ในเลกเชอร์ เขียน k เป็นบิตแล้วผลนี้ แยกเป็นผลคูณของ qubit แต่ละตัว ได้พอดี: qubit ที่ l หมุนเฟสไป 2πn/2l โดยไม่ขึ้นกับตัวอื่น

แตกเป็นผลคูณ

  1. QFT|n⟩ = 1√N Σk ej2πnk/N |k⟩
    นิยาม ใส่ x เป็น impulse ที่ตำแหน่ง n
  2. k = k12q−1 + k22q−2 + … + kq20
    เขียน k เป็นบิต — k₁ คือบิตบนสุด (qubit แรก)
  3. ej2πnk/N = Πl ej2πn kl / 2l
    เพราะ 2q−l/2q = 1/2l และ ea+b = eaeb
  4. QFT|n⟩ = ⊗l=1…q (|0⟩ + ej2πn/2l|1⟩)/√2
    ผลรวมของแต่ละ kl ∈ {0,1} แยกกันได้ → ไม่มี entanglement แต่ละ qubit เตรียมแยกกันได้

03 วงจร QFT — ชิ้นส่วนเดียวกับ FFT ทุกชิ้น

วงจรสร้างวงล้อในข้อ 02 ทีละ qubit ด้วยเกต 3 ชนิด และแต่ละชนิดมีคู่ใน FFT แบบ radix-2: H = DFT ขนาด 2 (butterfly), Rk ที่มีตัวควบคุม = คูณ twiddle factor, swap ตอนท้าย = กลับลำดับบิต (bit reversal) กด “ขั้นถัดไป” เพื่อดูสถานะหลังแต่ละเกต

เกตที่ใช้

H = 1√2[1 1; 1 −1] Rk = [1 0; 0 ej2π/2k]

ใช้เกตทั้งหมด q(q+1)/2 ตัว + swap ⌊q/2⌋ ตัว — โตแบบ q² ไม่ใช่ N

04 หาคาบ — งานที่ QFT ทำได้ดีจริง ๆ และเป็นหัวใจของ Shor's algorithm

ถ้าสถานะเป็น impulse train คาบ r (เลื่อนไป x₀) หลัง QFT จะเหลือยอดที่ k ≈ N/r, 2N/r, … เหมือน DFT ของ impulse train ส่วน x₀ แค่คูณเฟส ej2πkx₀/N — ขนาดไม่เปลี่ยน (สมบัติ time shift) นี่คือเหตุผลที่ใช้ได้: เราไม่รู้ x₀ แต่ก็ไม่จำเป็นต้องรู้ วัดได้ k มาหนึ่งค่า แล้ว k/N ≈ s/r ใช้เศษส่วนต่อเนื่อง (continued fraction) หา r

วัดหลาย ๆ ครั้ง แล้วเอา lcm ของตัวส่วนที่ได้ — จะได้ r
ครั้งที่วัดได้ kk/Nเศษส่วนต่อเนื่อง ≈ s/r′r′lcm สะสม
ยังไม่ได้วัด

ตัวอย่าง Shor: แยก 15 ด้วย a = 7

  1. f(x) = 7x mod 15 = 1, 7, 4, 13, 1, 7, 4, 13, …
    ฟังก์ชันนี้เป็นคาบเสมอ — ปัญหาคือหาคาบตรง ๆ บนคอมธรรมดาช้ามากเมื่อตัวเลขใหญ่
  2. Σx |x⟩|f(x)⟩ → วัด f ได้ 4 → เหลือ |2⟩ + |6⟩ + |10⟩ + …
    คอมควอนตัมคำนวณ f ทุก x พร้อมกัน วัดค่า f แล้วเหลือ impulse train คาบ r = 4 ที่ x₀ = 2 (สุ่ม)
  3. QFT → ยอดที่ k = 0, N/4, 2N/4, 3N/4
    ลองตั้ง r = 4 ข้างบน — ยอดอยู่ที่เดิมไม่ว่า x₀ จะเป็นเท่าไร
  4. r = 4 → 72 = 49 → gcd(48, 15) = 3, gcd(50, 15) = 5
    ถ้า r คู่: ar − 1 = (ar/2 − 1)(ar/2 + 1) ≡ 0 mod 15 จึงได้ตัวประกอบ 15 = 3 × 5

05 เร็วกว่า FFT จริงไหม — เร็วกว่ามาก แต่อ่านผลออกมาไม่ได้

FFT ใช้ประมาณ N log₂N = q·2q ครั้ง ส่วนวงจร QFT ใช้ q(q+1)/2 เกต ต่างกันแบบ exponential — แต่ QFT ไม่ได้ให้ array yk ออกมา วัดแล้วได้ k มาค่าเดียวตามความน่าจะเป็น |yk|² แล้วสถานะก็หายไป

เอา QFT มาแทน FFT ทำเสียง/ภาพไม่ได้ — การโหลด N ค่าเข้า amplitude ก็ใช้เวลาราว N อยู่แล้ว และอ่าน yk ครบทุกตัวต้องวัดซ้ำมหาศาล QFT คุ้มเฉพาะงานที่สถานะเกิดขึ้นเองในคอมควอนตัม และต้องการคำตอบแค่ “ยอดอยู่ตรงไหน” เช่นการหาคาบ (Shor) และ phase estimation
