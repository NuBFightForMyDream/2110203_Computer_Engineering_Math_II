00 Standard form ที่ใช้ในเฉลยนี้ — อ่านก่อน 1 นาที

Q1 Convex set & extreme points 1 pt

โจทย์

For each picture, is it a convex set? If so, mark all of the extreme points.
A. A line  ·  B. A quadrilateral (filled)  ·  C. A 3D triangular-based pyramid (filled)

แปล: แต่ละรูปเป็น convex set ไหม ถ้าใช่ให้มาร์ค extreme point ทั้งหมด

  1. นิยามที่ต้องใช้ (จำ 2 อันนี้ให้ได้)

    Convex set: เลือกจุด 2 จุด ใดก็ได้ ในเซต แล้วลากเส้นตรงเชื่อม — เส้นนั้นต้องอยู่ในเซต ทั้งเส้น ทุกครั้ง

    x, y ∈ S  ⇒  λx + (1 − λ)y ∈ S  สำหรับทุก λ ∈ [0, 1]

    Extreme point (จุดมุม): จุดในเซตที่ ไม่ได้อยู่ตรงกลาง ของเส้นตรงใด ๆ ที่ลากระหว่างสองจุดอื่นในเซต

    ทำไมสำคัญ: ใน LP คำตอบที่ดีที่สุดจะอยู่ที่ extreme point เสมอ (ถ้ามีคำตอบ) — simplex ก็คือการเดินจาก extreme point หนึ่งไปอีกจุด

  2. A · เส้นตรง (line segment)

    สองจุดใดก็ได้บนเส้น → ส่วนของเส้นตรงที่เชื่อมก็อยู่บนเส้นเดิม → convex

    จุดตรงกลางเส้น (สีฟ้า) อยู่กึ่งกลางระหว่างสองจุดอื่น จึง ไม่ใช่ extreme point เหลือแค่ ปลายทั้งสองข้าง ที่หาสองจุดมาคร่อมไม่ได้

    A Convex · extreme points = ปลายเส้น 2 จุด

    ถ้าตีความว่าเป็นเส้นตรงยาวไม่สิ้นสุด (line) ก็ยัง convex แต่ ไม่มี extreme point เลย — เขียนกำกับไว้ทั้งสองกรณีได้

  3. B · สี่เหลี่ยมที่มีมุมเว้าเข้าไป

    สังเกตมุมด้านในของรูป (จุด C) มันหักเข้าข้างใน → ลองลากเส้นจากปลายล่าง D ไปปลายขวา B เส้นจะ วิ่งออกนอกรูป (ส่วนสีแดง)

    แค่เจอ คู่เดียว ที่เส้นหลุดออกไป ก็สรุปได้ทันทีว่า ไม่ convex → ไม่ต้องมาร์ค extreme point

    ลองเลื่อน slider ใต้รูป: จุด P วิ่งรอบขอบรูป เส้น PB สีเขียว = อยู่ในรูป, สีแดง = หลุดออก

  4. C · ปิรามิดฐานสามเหลี่ยม (tetrahedron) แบบทึบ

    ทรงตันที่ไม่มีส่วนเว้า → เส้นเชื่อมสองจุดใดก็อยู่ข้างใน → convex

    Extreme point = มุมทั้ง 4 (ยอด 1 + มุมฐาน 3) จุดบนขอบหรือบนหน้าอยู่ระหว่างสองจุดอื่นได้เสมอ จึงไม่นับ

    C Convex · extreme points = 4 มุม

  5. สรุปคำตอบ

    รูปConvex?Extreme points
    A เส้นตรงYESปลาย 2 จุด
    B สี่เหลี่ยมเว้าNO— (มีเส้นเชื่อมที่หลุดนอกรูป)
    C ปิรามิดทึบYES4 มุม

Q2 True or false 2 pts

โจทย์

If you answer false, you must provide a reason.

A. If the feasible region has only one extreme point, it must be the optimal.
B. If there are at least two optimal extreme points, all feasible solutions are optimal.
C. The following optimization cannot be solved using linear programming:
  max 5x₁ + 2x₂ + 1/x₃  s.t.  x₁ ≤ x₂,  x₁ + x₂ + 1/x₃ ≤ 10,  5/x₃ ≥ 1,  x₁ ≤ −3, x₂ ≥ 0, x₃ ≥ 3
D. If the LP is degenerate, it is unbounded.

เคล็ดลับ: ตอบ False ต้องมี เหตุผลหรือ counterexample — วิธีที่ปลอดภัยที่สุดคือยกตัวอย่าง LP 2 ตัวแปรที่วาดรูปได้

  1. A · "มี extreme point เดียว → ต้องเป็นคำตอบ" — คิดหา counterexample

    ถ้ามี extreme point จุดเดียว เซตต้อง ไม่มีขอบเขต (เพราะเซตที่มีขอบเขตแล้วมีมุมเดียวคือจุดเดียว) ตัวอย่างที่ง่ายที่สุด: quadrant แรก

    max x + y  s.t.  x ≥ 0, y ≥ 0

    Extreme point มีจุดเดียวคือ (0, 0) แต่ isoprofit line x + y = k เลื่อนออกไปได้เรื่อย ๆ → unbounded ไม่มี optimal เลย

    A FALSE LP อาจ unbounded ได้ เช่น max x + y บน x, y ≥ 0 มี extreme point เดียวคือ (0,0) แต่ไม่มีคำตอบ optimal

  2. B · "มี optimal extreme point ≥ 2 จุด → ทุกจุดใน feasible region optimal"

    ใช้ LP ของข้อ 4 เลย: max 2.5x₁ + x₂ บนสามเหลี่ยม (0,0), (2,0), (0,5)

    ทั้ง (2, 0) และ (0, 5) ให้ z = 5 (optimal ทั้งคู่) แต่ (0, 0) ให้ z = 0 → ไม่ optimal

    สิ่งที่ถูกคือ: ทุกจุดบน เส้นตรงที่เชื่อม สอง optimal extreme points (convex combination) เป็น optimal — ไม่ใช่ทั้ง region

    B FALSE มีแค่ส่วนของเส้นระหว่างสองจุดนั้นที่ optimal เช่น (0,0) ใน LP ข้างบนไม่ optimal

  3. C (1/3) · ดูว่า "ไม่เป็นเส้นตรง" ตรงไหน

    ตัวที่ดูไม่ linear มีแค่ 1/x₃ และ 5/x₃ — แต่สังเกตว่า x₃ ไม่เคยโผล่มาแบบอื่นเลย มีแต่ในรูป 1/x₃

    ไอเดีย: ตั้งตัวแปรใหม่ t = 1/x₃ แล้วทุกอย่างจะกลายเป็น linear ใน t

    นี่คือ trick ที่ออกสอบบ่อย — ก่อนจะบอกว่า "ไม่ใช่ LP" ให้ลองเปลี่ยนตัวแปรก่อนเสมอ

  4. C (2/3) · แปลงข้อจำกัดของ x₃ เป็นของ t

    เพราะ x₃ ≥ 3 > 0 ฟังก์ชัน 1/x เป็นฟังก์ชันลดลง → อสมการกลับทิศ

    x₃ ≥ 3  ⇔  t = 1/x₃ ≤ 1/3 5/x₃ ≥ 1  ⇔  5t ≥ 1  ⇔  t ≥ 1/5

    ดูกราฟ: ช่วง x₃ ∈ [3, 5] ถูกส่งไปเป็น t ∈ [1/5, 1/3] พอดี (ทุก t ในช่วงนี้ย้อนกลับเป็น x₃ = 1/t ได้)

  5. C (3/3) · เขียนเป็น LP ได้ → ข้อความนี้ FALSE

    max 5x₁ + 2x₂ + t s.t.  x₁ − x₂ ≤ 0   x₁ + x₂ + t ≤ 10   1/5 ≤ t ≤ 1/3,  x₁ ≤ −3,  x₂ ≥ 0

    ทุกอย่าง linear แล้ว (ส่วน x₁ ≤ −3 แทน x₁ = −3 − x₁′, x₁′ ≥ 0 ได้) แก้เสร็จแล้วค่อยแปลงกลับ x₃ = 1/t

    แถม: ถ้าแก้ LP นี้จะได้ x₁ = −3, x₂ = 12.8, t = 1/5 (x₃ = 5) และ z = 10.8 — แปลว่าแก้ได้จริงด้วย LP

    C FALSE แทน t = 1/x₃ จะได้ 1/5 ≤ t ≤ 1/3 และทุกข้อจำกัดเป็น linear → แก้ด้วย LP ได้

  6. D · "Degenerate → unbounded"

    Degenerate = มี BFS ที่ basic variable บางตัว เท่ากับ 0 (ในรูป 2 มิติ: มีมุมที่เส้นข้อจำกัดผ่าน มากกว่า 2 เส้น) — เป็นเรื่องของ "มุม" ไม่ใช่เรื่อง "ขอบเขต"

    max x + y  s.t.  x + y ≤ 2,  x ≤ 1,  y ≤ 1,  x, y ≥ 0

    ที่มุม (1, 1) มี 3 เส้นผ่าน → slack ของ x + y ≤ 2 เป็น basic แต่ = 0 → degenerate แต่ region เป็นสี่เหลี่ยมจัตุรัสปิด → bounded และ optimal = 2

    D FALSE degenerate แปลว่ามี basic variable = 0 ไม่เกี่ยวกับ unbounded (ตัวอย่างข้างบน degenerate แต่มี optimal = 2)

Q4 Simplex method ด้วยมือ 5 pts

โจทย์

Maximize z = 2.5x₁ + x₂ by using the simplex method by hand. Show work.
Constraints: 3x₁ + x₂ ≤ 15,  5x₁ + 2x₂ ≤ 10,  x₁, x₂ ≥ 0

Simplex = เดินตามมุม: เริ่มที่มุม (0,0) → เลือกตัวแปรที่ทำให้ z เพิ่ม (entering) → เดินไปจนชนข้อจำกัดแรก (ratio test เลือก leaving) → pivot → ทำซ้ำจนแถว z ไม่มีค่าติดลบ

รูปด้านบนแสดงว่าตอนนี้ tableau "อยู่ที่มุมไหน" ของ feasible region

  1. ดูรูปก่อน (ไม่บังคับ แต่ช่วยให้ไม่หลง)

    เส้น 3x₁ + x₂ = 15 ตัดแกนที่ (5,0), (0,15) · เส้น 5x₁ + 2x₂ = 10 ตัดแกนที่ (2,0), (0,5)

    Region จริงคือสามเหลี่ยม (0,0), (2,0), (0,5) — ข้อจำกัดแรกอยู่นอกสุด จึง redundant (ไม่มีผลเลย)

  2. แปลงเป็น standard form (เติม slack)

    max z = 2.5x₁ + x₂ 3x₁ + x₂ + s₁ = 15 5x₁ + 2x₂ + s₂ = 10 x₁, x₂, s₁, s₂ ≥ 0

    เขียนแถว z ให้ทุกอย่างอยู่ฝั่งซ้าย: z − 2.5x₁ − x₂ = 0

  3. Tableau เริ่มต้น: BV = s₁, s₂ (คือจุด origin)

    อ่าน tableau: NBV x₁ = x₂ = 0 · BV s₁ = 15, s₂ = 10 · z = 0

  4. เลือก entering variable: ค่าติดลบที่สุดในแถว z

    แถว z มี −2.5 (x₁) กับ −1 (x₂) → เลือก x₁ เพราะเพิ่ม x₁ ทีละ 1 แล้ว z เพิ่ม 2.5 (เร็วกว่า)

    ค่าติดลบในแถว z = "ยังมีทางทำให้ z ดีขึ้นได้" · กติกานี้ใช้กับ max (ถ้าเป็น min ให้แปลงเป็น max −z ก่อน)

  5. Ratio test: เลือก leaving variable

    หาร RHS ด้วยค่าในคอลัมน์ x₁ (เฉพาะค่าที่ เป็นบวก) → 15/3 = 5, 10/5 = 2 → ตัวน้อยสุดคือ 2 แถว s₂ → s₂ ออก

    ความหมาย: เพิ่ม x₁ ได้มากสุดแค่ 2 ก่อนที่ s₂ จะติดลบ (ชนเส้น 5x₁ + 2x₂ = 10) — ถ้าไปถึง 5 จะหลุดออกนอก region (ดูรูป)

  6. Pivot (ตัวสีน้ำเงิน = 5)

    R₂ ← R₂ / 5  → x₁ + (2/5)x₂ + (1/5)s₂ = 2 R₁ ← R₁ − 3R₂  → −(1/5)x₂ + s₁ − (3/5)s₂ = 9 R₀ ← R₀ + 2.5R₂  → z + 0·x₂ + (1/2)s₂ = 5

    ตอนนี้อยู่ที่มุม (x₁, x₂) = (2, 0), z = 5

  7. เช็ค optimal: แถว z ไม่มีค่าติดลบแล้ว → หยุด

    แถว z: 0, 0, 0, 1/2 ทั้งหมด ≥ 0 → optimal

    Optimal x₁ = 2, x₂ = 0, z = 5 (s₁ = 9 คือข้อจำกัดแรกยังเหลือที่ว่าง 9 หน่วย)

  8. จุดหลอก: x₂ เป็น NBV แต่ค่าในแถว z = 0 → มี alternative optimum

    ค่า 0 แปลว่าเอา x₂ เข้า basis ได้ โดย z ไม่เปลี่ยน ลอง pivot ต่ออีกครั้ง:

    Ratio: แถว s₁ ค่าเป็นลบ (−1/5) ข้าม · แถว x₁: 2 ÷ 2/5 = 5 → x₁ ออก

    ได้มุม (0, 5) และ z = 5 เท่าเดิม → ทุกจุดบนเส้นจาก (2,0) ไป (0,5) เป็น optimal

    เหตุผลทางรูป: 2.5x₁ + x₂ = ½(5x₁ + 2x₂) → isoprofit line ขนาน กับข้อจำกัดที่ 2 พอดี

  9. สรุปคำตอบ

    คำตอบ

    z* = 5 ที่ (x₁, x₂) = (2, 0) (จาก simplex รอบแรก)

    และมี alternative optima: ทุกจุด λ(2, 0) + (1 − λ)(0, 5), λ ∈ [0, 1] บนเส้น 5x₁ + 2x₂ = 10

Q5 Two-phase method 3 pts

โจทย์

Solve the following LP using the two-phase method. Show work.
min −x₁ + 5x₂  s.t.  −x₁ + 3x₂ ≥ 12,  x₁ ≥ 0,  x₂ unrestricted

ทำไมต้อง two-phase: ข้อจำกัด ≥ ทำให้จุด origin ไม่ feasible (−0 + 0 = 0 ≱ 12) เลยไม่มี BFS เริ่มต้นง่าย ๆ แบบข้อ 4

Phase 1 = เติม artificial a₁ แล้วหา BFS ที่ทำให้ a₁ = 0 · Phase 2 = เริ่มจาก BFS นั้น แก้ objective จริง

  1. ดูรูปปัญหา

    Region คือครึ่งระนาบเหนือเส้น x₂ = 4 + x₁/3 ที่ x₁ ≥ 0 (ไม่มีขอบเขตด้านบน) และ x₂ ติดลบได้ (แต่ในที่นี้ข้อจำกัดบังคับให้ x₂ ≥ 4 อยู่แล้ว)

    จะ min −x₁ + 5x₂ → อยากให้ x₂ เล็ก x₁ ใหญ่ แต่เพิ่ม x₁ 3 หน่วย ต้องเพิ่ม x₂ 1 หน่วย (เสีย 5 ได้ 3) → ไม่คุ้ม

  2. แปลงตัวแปร free: x₂ = x₂⁺ − x₂⁻

    min z = −x₁ + 5x₂⁺ − 5x₂⁻−x₁ + 3x₂⁺ − 3x₂⁻ ≥ 12,  x₁, x₂⁺, x₂⁻ ≥ 0

  3. ≥ → ลบ surplus e₁ แล้วบวก artificial a₁

    −x₁ + 3x₂⁺ − 3x₂⁻ − e₁ + a₁ = 12

    ถ้าไม่มี a₁: ให้ตัวอื่นเป็น 0 จะได้ e₁ = −12 < 0 ใช้เป็น BV ไม่ได้ → เลยต้องเติม a₁ ให้เป็น BV เริ่มต้น (a₁ = 12)

    a₁ เป็นตัวปลอม — ถ้าคำตอบสุดท้ายมี a₁ > 0 สมการเดิมจะไม่จริง เลยต้องไล่มันให้เป็น 0 ใน Phase 1

  4. Phase 1: min w = a₁ (เขียนเป็น max −w)

    แถวแรก: −w + a₁ = 0 แต่ a₁ เป็น BV ต้องมีค่า 0 ในแถว objective → R₀ ← R₀ − R₁

    RHS แถว 0 = −12 แปลว่าตอนนี้ w = 12 (ผลรวม artificial)

  5. Phase 1 pivot: x₂⁺ เข้า, a₁ ออก

    ค่าติดลบที่สุดในแถว 0 คือ −3 (x₂⁺) · ratio มีแถวเดียว 12 ÷ 3 = 4 → a₁ ออก

    w = 0 แล้ว → Phase 1 จบ ได้ BFS: x₂⁺ = 4 (คือจุด (x₁, x₂) = (0, 4))

  6. Phase 2: ทิ้งคอลัมน์ a₁ ใส่ objective จริง

    min z = −x₁ + 5x₂⁺ − 5x₂⁻ ⇔ max −z → แถว 0: (−z) − x₁ + 5x₂⁺ − 5x₂⁻ = 0

    x₂⁺ เป็น BV แต่มีค่า 5 ในแถว 0 → ต้องทำให้เป็น 0 ก่อน: R₀ ← R₀ − 5R₁

  7. เช็ค optimal → เสร็จ

    แถว 0 = 2/3, 0, 0, 5/3 ไม่มีค่าติดลบ → optimal · RHS = −20 คือ −z = −20 → z = 20

    คำตอบ x₁ = 0, x₂ = x₂⁺ − x₂⁻ = 4 − 0 = 4, zmin = 20

    x₂⁻ มีค่า 0 ในแถว 0 แต่ไม่ใช่ alternative optimum จริง — ถ้าเพิ่ม x₂⁻ ระบบจะเพิ่ม x₂⁺ ตามเท่ากัน ค่า x₂ ที่แท้จริงยังเป็น 4

  8. ตรวจคำตอบแบบไม่ใช้ tableau

    −x₁ + 3x₂ ≥ 12  ⇒  x₂ ≥ 4 + x₁/3z = −x₁ + 5x₂ ≥ −x₁ + 5(4 + x₁/3) = 20 + (2/3)x₁ ≥ 20

    เท่ากับ 20 ได้ตอน x₁ = 0, x₂ = 4 พอดี ✓ (ในรูป: isocost line ค่า 20 แตะ region ที่มุม (0, 4))

Q8 Hamtaro first crisis — กระจายสินค้าตอนของไม่พอ 4 pts

โจทย์

N factories at (xfi, yfi) producing pi snacks/day; M stores at (xsi, ysi) demanding si/day; Σpi < Σsi; goods can only travel D km from where they are produced. Dissatisfaction of a store = (unmet supplies) / (demanded supplies).

8.1 minimize the average dissatisfaction · 8.2 minimize the dissatisfaction of the most dissatisfied store · 8.3 compare the optimal values.

Hint ของโจทย์: ระยะทาง, pi, sj, D เป็น ค่าคงที่ (รู้ก่อนแก้) — ตัวแปรมีแค่ "ส่งจากโรงงานไหนไปร้านไหนเท่าไหร่" ดังนั้นสูตรระยะทางที่มีรากที่สองไม่ทำให้ไม่ linear

รูปด้านบนเป็นตัวอย่างขนาดเล็ก (3 โรงงาน 5 ร้าน — ตัวเลขสมมติ) แก้ LP จริงสด ๆ: ลองสลับ 8.1 / 8.2 และเลื่อน D

4

  1. แยก "ค่าคงที่" กับ "ตัวแปร"

    ค่าคงที่: ตำแหน่ง, pi, sj, D และระยะทาง dij = √((xfi − xsj)² + (yfi − ysj)²) คำนวณเป็นตัวเลขได้ก่อนเลย

    ตัวแปร:  xij ≥ 0 = จำนวน snack ที่ส่งจากโรงงาน i ไปร้าน j ต่อวัน

  2. ข้อจำกัดระยะทาง

    ส่งได้เฉพาะคู่ที่ dij ≤ D (เส้นประในรูป = คู่ที่ส่งได้):

    xij = 0  สำหรับทุกคู่ที่ dij > D

    หรือจะไม่สร้างตัวแปรของคู่นั้นเลยก็ได้ — ไม่ต้องใช้ if/else ใน LP เพราะ dij รู้ค่าล่วงหน้า

  3. ข้อจำกัดกำลังผลิตของโรงงาน

    Σj xij ≤ pi  ∀ i = 1…N

  4. ตัวแปรช่วย: dissatisfaction ของแต่ละร้าน

    ของที่ร้าน j ได้รับ = Σi xij ไม่ควรเกิน sj (ไม่งั้นความไม่พอใจติดลบ ไปหักกลบร้านอื่น)

    uj = (sj − Σi xij) / sj  ⇔  sj uj + Σi xij = sj,  uj ≥ 0

    sj เป็นค่าคงที่ → หารด้วย sj ยัง linear · และ uj ≥ 0 บังคับ Σxij ≤ sj ให้อัตโนมัติ

  5. 8.1 · Objective: เฉลี่ยน้อยที่สุด

    min  (1/M) Σj uj

    ดูรูป: LP ชอบส่งให้ร้าน เล็ก ก่อน (ส่ง 1 ชิ้นลด uj ได้ 1/sj ซึ่งมากถ้า sj เล็ก) → ร้านใหญ่โดนทิ้ง ความไม่พอใจสูงมาก

  6. 8.1 · Standard form

    min (1/M) Σj uj s.t. Σj xij + ti = pi  ∀ i (ti = slack)   Σi xij + sj uj = sj  ∀ j   xij = 0  ∀ (i, j) ที่ dij > D   xij, uj, ti ≥ 0

  7. 8.2 · min ของ max → เทคนิค "ตัวแปรเพดาน"

    max(u₁,…,uM) ไม่ linear โดยตรง → ตั้งตัวแปร z ที่ต้อง สูงกว่าหรือเท่ากับทุก uj แล้ว min z

    min z  s.t.  z ≥ uj  ∀ j  (+ ข้อจำกัดเดิมทั้งหมด)

    Hint ของโจทย์: ร้านที่ไม่พอใจที่สุดคือร้านที่ uj = z พอดี (ข้อจำกัด z ≥ uj ตึง) · min z จะกดเพดานลงจนชนร้านที่แย่ที่สุด

    ดูรูป: ทุกร้านถูกเกลี่ยให้ไม่พอใจเท่า ๆ กัน

  8. 8.2 · Standard form

    min z s.t. z − uj − vj = 0  ∀ j (vj = surplus)   Σj xij + ti = pi  ∀ i   Σi xij + sj uj = sj  ∀ j   xij = 0  ∀ (i, j) ที่ dij > D   xij, uj, ti, vj, z ≥ 0

  9. 8.3 · เทียบค่า optimal

    สำหรับทุกแผนการส่ง x: ค่ามากสุด ≥ ค่าเฉลี่ยเสมอ maxj uj(x) ≥ (1/M)Σ uj(x)

    OPT8.2 = minx maxj uj(x)  ≥  minx (1/M)Σj uj(x) = OPT8.1

    และทั้งคู่ > 0 เพราะ Σp < Σs ต้องมีอย่างน้อยหนึ่งร้านที่ได้ไม่ครบ · เท่ากันได้เมื่อแผนที่ดีที่สุดของ 8.1 เกลี่ยทุกร้านให้เท่ากันพอดี

    8.3 OPT(8.2) ≥ OPT(8.1) > 0 เพราะ max ≥ average ทุกแผน — ในรูปตัวอย่าง 0.25 ≥ 0.167
